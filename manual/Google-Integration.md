# 계정별 Google 연동

서버 창의 **계정 관리 → 계정 선택 → Google 연동**에서 설정합니다. Gmail, Google Drive, Google Calendar의 검색·읽기만 지원합니다. 메일 발송, 파일 수정, 일정 생성·삭제 기능은 제공하지 않습니다.

## 최초 설정

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만들고 사용할 서비스의 Gmail API, Google Drive API, Google Calendar API를 사용 설정합니다.
2. Google Auth Platform에서 OAuth 동의 화면을 설정합니다. 개인 테스트라면 대상 Google 계정을 테스트 사용자로 추가합니다. 공개 배포 시에는 요청 범위에 따라 Google 검증이 필요할 수 있습니다.
3. OAuth 클라이언트 유형을 **데스크톱 앱**으로 만들어 클라이언트 ID와 클라이언트 보안 비밀번호를 받습니다. API 키와 다른 값입니다.
4. 게이트웨이 계정 편집의 Google OAuth 클라이언트 설정에 두 값을 입력합니다. 보안 비밀번호는 이후 비워 두면 유지됩니다.
5. 사용할 서비스를 체크하고 **Google 연결 / 권한 업데이트**를 누릅니다. 서버가 실행 중인 컴퓨터의 브라우저에서 Google 계정을 선택하고 읽기 권한을 승인합니다. 인증 콜백은 임시 로컬 포트(127.0.0.1)를 사용하며 외부 포트를 열 필요가 없습니다.
6. 서버 창에 연결된 Google 이메일이 표시되는지 확인합니다. 서비스를 추가한 뒤에는 권한 업데이트를 다시 진행합니다. 일부 권한을 승인하지 않으면 해당 서비스는 도구로 제공되지 않습니다.

## 사용

해당 게이트웨이 계정으로 로그인하고 앱 도구를 활성화한 뒤 다음처럼 요청합니다.

- “최근 이메일 확인” — 별도 검색 조건 없이 최근 받은 메일 최대 10개를 조회합니다.
- “지난주 항공권 메일을 찾아 출발 시간을 알려줘.”
- “드라이브 확인” — 최근 수정 파일 최대 10개를 조회합니다.
- “Google Drive에서 회의록을 찾아 결정 사항을 요약해 줘.”
- “일정 확인” — 구독·공유 캘린더를 포함한 연결된 모든 캘린더의 앞으로 7일 일정을 조회합니다.
- “오늘 일정”, “내일 일정”, “이번 주 일정” — 캘린더 시간대를 기준으로 기간을 계산합니다.

서비스별 기본 스킬은 함께 제공되며 활성 서비스의 도구가 있는 대화에만 포함됩니다. 별도 스킬 설치는 필요하지 않습니다. 서비스 체크 변경은 즉시 저장되며, 체크를 해제하면 진행 중인 대화의 후속 호출도 차단됩니다. 이미 답변이나 대화 기록에 포함된 내용까지 삭제되지는 않습니다.

## 읽기 범위

- Gmail: 검색 결과의 발신자·제목·날짜·일부 내용 및 선택한 메일 본문. 첨부파일은 이름만 표시하며 읽지 않습니다.
- Drive: 파일 메타데이터 검색. 본문은 Google Docs·Slides의 텍스트, Sheets 첫 탭의 CSV, UTF-8 텍스트 파일을 지원합니다. PDF·Office·이미지 등 바이너리 파일의 내용 추출은 지원하지 않습니다.
- Calendar: 접근 가능한 캘린더 목록, 기간·키워드 검색, 일정 상세. 일반 일정 질문은 숨김·선택 해제된 구독 캘린더도 포함해 모두 조회하며, 특정 캘린더를 지정하면 그 캘린더만 조회합니다. 기본 캘린더 시간대를 기준으로 공통 기간을 적용하고 결과에 캘린더 이름을 표시합니다. 권한 부족 등으로 조회하지 못한 캘린더는 별도로 표시합니다. 반복 일정을 기간 안에서 펼쳐 조회합니다.
- 검색 결과는 페이지 단위이며 후속 토큰으로 계속 조회할 수 있습니다. 긴 메일·문서는 최대 24,000자까지 전달하고 잘림을 표시합니다. Google 응답은 요청당 4 MiB로 제한됩니다.

## 인증 정보와 연결 해제

각 게이트웨이 계정의 인증 정보는 앱 데이터 폴더의 `google-integration`에 별도로 저장됩니다. 토큰과 클라이언트 보안 비밀번호는 암호화된 파일에 저장되고 로컬 키 파일과 함께 소유자 전용 권한을 사용합니다. 키가 같은 컴퓨터에 있으므로 운영체제 계정에 대한 접근 통제도 필요합니다. 두 파일을 함께 외부에 공유하지 마세요.

LLM에는 인증 정보가 전달되지 않으며 서버가 현재 로그인한 게이트웨이 계정으로 Google 요청을 실행합니다. 연결 해제는 로컬 토큰을 삭제합니다. Google 측 앱 권한까지 철회하려면 [Google 계정의 연결 관리](https://myaccount.google.com/connections)에서 삭제하세요. 같은 OAuth 앱을 이용하는 다른 연결에도 영향을 줄 수 있습니다.
