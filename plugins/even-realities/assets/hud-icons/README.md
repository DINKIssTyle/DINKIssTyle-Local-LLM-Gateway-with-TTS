# 1:1 비트맵 HUD 아이콘 편집

이 폴더의 **24×24 PNG 파일**이 실제 앱이 읽는 편집 원본입니다. 1픽셀이 안경 화면의 1픽셀에 대응하며 확대·축소 없이 표시합니다.

| 파일 | 용도 |
| --- | --- |
| glasses-mic-on.png | 안경 마이크 켜짐 |
| glasses-mic-off.png | 안경 마이크 꺼짐 |
| phone-mic-on.png | 휴대폰 마이크 켜짐 |
| phone-mic-off.png | 휴대폰 마이크 꺼짐 |
| mode-ai.png | 헤더의 AI 글자를 대체하는 로봇 아이콘 |
| mode-translate.png | 헤더의 번역 글자를 대체하는 번역 아이콘 |
| status-idle.png | 대기 상태 · 모래시계 |
| status-listening.png | 실제 오디오 수신 중 · 파형 |
| status-transcribing.png | 전사 처리 · 문서와 연필 |
| status-thinking.png | 생각·조회·판별 처리 · 두뇌 |
| status-warning.png | 오류·마이크 꺼짐·음성 엔진 준비·오디오 수신 대기 · 삼각형 느낌표 |
| status-prompt-0.png ~ status-prompt-8.png | 실제 프롬프트 처리율 · 0~100%를 12.5% 간격으로 표시 |
| status-prompt-unknown.png | 프롬프트 처리율이 제공되지 않은 상태 |

`preview.html`에서 확대 보기와 실제 24×24 배치를 비교할 수 있습니다. `ai-trigger.png`는 이전 참고 원본으로 보존했으며, 현재 헤더의 AI 아이콘은 `mode-ai.png`입니다.

## 편집·적용

1. PNG를 픽셀 단위로 편집하고 **파일명과 24×24 크기를 유지**하세요. 다른 크기는 늘이거나 줄이지 않고 오류로 처리합니다.
2. 제공 파일은 투명 배경과 흰색 픽셀의 1-bit 흑백 PNG입니다. 흰색은 안경의 녹색, 투명/검은 픽셀은 꺼짐으로 표시합니다. RGB/RGBA PNG도 읽을 수 있습니다. 가능하면 안티앨리어싱 없이 편집하세요.
3. 플러그인을 다시 빌드/패키징하고 업데이트합니다. 개발 모드에서는 PNG 변경을 감지해 미리보기를 새로고침합니다. 일반 빌드/패키징은 편집한 PNG를 덮어쓰지 않습니다.
4. `node draw-bitmaps.mjs`는 모든 제공 원본을 다시 생성합니다. `node draw-bitmaps.mjs --new-only`는 마이크 원본을 제외한 모드/상태 아이콘을 다시 생성합니다. 특정 파일만 재생성하려면 `--only=status-thinking,status-warning`처럼 지정합니다. **다시 생성하면 해당 PNG의 직접 편집 내용을 덮어씁니다.**

PNG는 최초 한 번 읽어 SDK용 packed Gray4(2픽셀/바이트)로 변환·캐시합니다. 하나당 288바이트이며 PNG 파일 자체를 안경에 보내지 않습니다. 모드·상태 아이콘과 꺼진 마이크는 약 절반 밝기로 변환합니다.

## 표시 규칙

- AI: `[로봇 아이콘 호출어] 마이크 아이콘 상태 아이콘`
- 번역: `[번역 아이콘] EN→KO 마이크 아이콘 상태 아이콘`
- 대기/듣기/전사 처리만의 상태 문구는 아이콘으로 대체합니다. 준비 중, 연결 중, 오디오 미수신, 오류, 질문 대기, LLM 처리 진행률은 필요한 텍스트로 유지합니다.
- 마이크 열기 응답만으로 파형 아이콘을 켜지 않습니다. 실제 PCM을 받은 뒤 듣기 상태가 됩니다. 확정 전사가 처리 중이면 문서 아이콘을 표시합니다.
- 아이콘 3개와 텍스트를 기존 27px 한 줄 안에 배치하고, 본문 높이와 시계·배터리 영역은 유지합니다. SDK의 이미지 4개/텍스트 8개/전체 12개 한도 안에서 동작합니다.
- 상태 변화 시에만 새 비트맵을 직렬 전송합니다. 애니메이션이나 반복 전송 타이머는 없습니다. 이미지 전송 실패 시 기존 텍스트 안내로 복귀합니다.

## AI 간결 레이아웃

폰 설정 → 화면 표시 → AI 모드 상단 레이아웃 → 간결을 선택하면 x=552, y=1의 상태 아이콘 한 개만 표시합니다. 시각·배터리·호출어·마이크 구분·상태 문구는 숨기며 번역 모드는 기존 헤더를 유지합니다. 오류를 우선하고, AI 처리 단계, 전사, 듣기 상태 순서로 표시합니다. 답변 생성은 기존 mode-ai.png를 사용합니다. 프롬프트 링은 실제 처리율을 아래 단계로 양자화하며, 알 수 없는 처리율을 임의로 증가시키지 않습니다. 새 아이콘도 화면 밝기 옵션을 따릅니다.
