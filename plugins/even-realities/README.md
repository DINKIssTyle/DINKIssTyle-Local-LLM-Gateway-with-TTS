# DKST AI Gateway — Even G2

G2용 Even Hub 웹 앱입니다. 휴대폰 Even Realities 앱에서 실행하고 G2의 화면·마이크·터치 입력을 연결합니다. 일반 브라우저에서는 설정과 화면 미리보기를 사용할 수 있으며 G2 녹음은 Even 앱 안에서만 가능합니다.

## 1.3.2 — LM Studio 대화 연결과 텍스트 입력

현재 패키지는 **1.3.2**입니다. 이번 버전은 Mac 게이트웨이를 완전히 종료·재실행하고 안경 앱 패키지도 업데이트해야 합니다.

- 계정의 실제 LLM 모드를 조회하여 LM Studio에는 `input`/`system_prompt`, OpenAI 호환 서버에는 `messages`를 보냅니다. `input is required` 오류를 수정했습니다. 기존 게이트웨이의 도구·메모리·EmbeddingGemma 2 + JEV 경로를 그대로 사용합니다.
- LM Studio의 `message.delta`, `chat.end`, 게이트웨이의 `request.complete`를 읽습니다. 최종 답변은 임시 내용을 교체하며 추론 이벤트는 답변에 넣지 않습니다. 오류 원문은 텍스트 답변 영역에도 남깁니다.
- 마이크 아래 텍스트 질문 입력창과 전송 버튼을 추가했습니다. 호출어 없이 같은 AI 대기열로 질문을 보내며, 답변은 휴대폰과 안경 화면에 표시합니다.
- 하단 기본 여백 120px과 안전 영역, 키보드가 가리는 높이를 반영한 추가 여백을 적용했습니다. 입력 글자 크기를 16px로 맞춰 iPhone의 입력 시 자동 확대를 줄였습니다.

검증: 양쪽 모드의 요청 형식, LM Studio 스트림·최종 답변 교체, 오류 원문과 빈 답변 표시, 텍스트 입력 대기열, 녹음 정지 회귀 테스트를 통과했습니다. 실제 iPhone 키보드와 G2 화면은 업데이트 후 확인이 필요합니다.

## 1.3.1 — 두 번째 탭으로 녹음 정지

1.3.1의 기본 API 주소는 `http://192.168.1.4:2806`입니다. 안경 앱 패키지만 업데이트하면 적용되며 Mac 게이트웨이 재시작은 필요하지 않습니다.

- 녹음 준비·마이크 열기 응답 대기 중에도 다시 탭하면 정지합니다. 취소 후 늦게 도착한 마이크 시작 응답은 마이크를 다시 닫아 처리합니다.
- 정지 요청 즉시 새 음성 수신을 중단하고, G2의 마이크 종료 응답을 확인합니다. 종료 확인에 실패하면 오류를 표시하며 다시 탭해 종료를 재시도합니다.
- 정지 전에 받은 음성의 최종 전사·저장은 계속합니다. 상태 줄에는 녹음 정지와 남은 처리 상태를 구분해서 표시합니다.

검증: 준비 중 취소, 늦은 마이크 시작 응답, 임시 전사 응답 대기 중 정지, 종료 실패 후 재시도를 SDK 모의 테스트로 확인했습니다. 실제 G2의 터치와 마이크 종료는 업데이트 후 기기에서 확인해야 합니다.

## 1.3.0 — 말하는 도중 자막 갱신

1.3.0의 기본 API 주소는 `http://192.168.1.4:2806`입니다. 이번 버전은 게이트웨이와 안경 앱을 모두 업데이트해야 합니다.

- **음성 모드 → 실시간 전사**에서 마이크를 시작하면, 최초 약 1.2초 오디오와 0.4초 이상의 음성을 확보한 뒤 임시 자막을 요청합니다. 이후 약 1초 간격으로 최신 누적 오디오를 전사합니다. 처리 지연 시에는 최신 초안 하나만 대기합니다.
- LocalAgreement-2로 연속 두 결과의 일치하는 앞부분을 안정화합니다. 수정될 수 있는 꼬리에는 `…`를 표시합니다. 발화 종료 후 전체 문장으로 보정하며, 임시 자막은 저장·트리거 판정에 사용하지 않습니다.
- 최종 결과는 기존 SQLite에 저장합니다. AI 답변은 별도 큐로 처리하므로 답변 생성 중에도 전사를 계속합니다. 답변 아래에 최신 자막을 짧게 표시하고, 답변 완료 약 8초 뒤 자막 화면으로 돌아갑니다.
- AI 호출어는 **쉼표로 여러 개** 입력할 수 있습니다. 예: `웬즈데이, 웬즈 데이, 웸즈 데이`. 띄어쓰기와 영문 대소문자를 무시하므로 앞의 두 표현은 같은 호출어입니다. 정규화 후 최대 8개, 각각 40자까지 등록합니다. 등록한 표현만 비교하며 임의의 유사 단어를 넓게 추측하지 않습니다.
- 상태 줄 왼쪽에는 `전사 저장됨 · AI 호출어: 웬즈데이`, 오른쪽에는 `16:14 / 75%`를 표시합니다. 호출어가 여러 개면 첫 표현을 대표로 표시하고, 긴 문구는 말줄임 처리합니다. 본문에는 전사·답변만 표시합니다.
- 마이크를 열기 전에 모델을 준비합니다. 처음 모델을 불러올 때 준비 시간이 필요하며, 준비가 끝난 뒤 녹음을 시작합니다.

검증: 실제 MLX GPU에서 한국어 합성 음성 1.3초 → 2.3초 → 3.3초 입력에 따라 문장이 확장됐고 각 임시 추론은 약 0.39~0.41초였습니다. 초안 중 DB 미기록, 최종 저장, 초안 호출어 무시, 종료 후 늦은 응답 무시, LLM 대기 중 전사 지속을 테스트했습니다. 실제 G2 BLE·Wi-Fi 상태에 따른 지연과 장시간 동작은 기기에서 확인해야 합니다.

전송은 Bearer 인증을 사용하는 HTTP 누적 스냅샷 방식이며 WebSocket은 추가하지 않았습니다. API는 `/api/stt/warmup`(준비), `/api/stt/preview`(화면 전용), `/api/stt/transcribe`(최종 저장)로 나뉩니다. [구현 상세](STREAMING_PLAN.md)를 참고하세요.

## 1.2.1 — 상태 표시 한 줄

우상단을 **`16:14 / 75%`** 한 줄로 통합했습니다. 폰 배터리는 표시하지 않으며, 잔량을 알 수 없으면 `16:14 / --`로 표시합니다. 상태 영역은 64 px에서 32 px로 줄이고 본문 높이는 224 px에서 256 px로 늘렸습니다. 안경 앱 패키지만 업데이트하면 적용되며 게이트웨이 재시작은 필요하지 않습니다.

실시간 스트리밍은 [설계안](STREAMING_PLAN.md)에 정리했습니다. 1.2.1에는 상태 줄 수정만 구현했고, 스트리밍 알고리즘은 설계 단계입니다.

## 1.2.0 — Apple Silicon MLX Turbo와 상태 표시

현재 패키지는 **1.2.0**, 기본 API 주소는 `http://192.168.1.4:2806`입니다.

- macOS Apple Silicon에서는 모델 관리자에서 **Whisper Large-v3-Turbo (MLX / Apple Silicon)**를 설치하면 이 모델을 우선 사용합니다. FP16 가중치는 약 1.61 GB이며, MLX Whisper 0.4.3과 Silero 음성 감지를 함께 사용합니다. Base ONNX는 다른 플랫폼과 기존 설치의 기본 경로로 유지합니다. 필요하면 서버 환경 변수 `DKST_STT_MODEL=whisper-base`로 Base를 지정할 수 있습니다.
- M4 Pro / 64 GB에서 한국어 합성 음성으로 측정한 결과: 모델 로딩 약 9.35초, 최초 5.11초 샘플 전사 1.80초, 재사용 0.45초. 11.24초 샘플은 재사용 시 0.54~0.55초였습니다. 사용자의 G2 음성과 장시간 연속 녹음 속도를 보장하는 수치는 아닙니다.
- 반복 문장, 낮은 디코딩 신뢰도, 불완전한 Base 디코딩 결과는 전사 저장과 AI 호출에서 제외합니다. 연속 모드에서 음성 내부의 무음 구간을 임의로 붙이지 않도록 수정했습니다. 인식하지 못한 구간을 추측해 표시하지 않는 쪽을 우선합니다.
- 안경 화면 우상단에 현재 시각을, 아래에 **안경 배터리 %**를 표시합니다. 시각은 휴대폰 현지 시간이며 매분 갱신합니다. 안경 배터리는 SDK 조회와 상태 변경 이벤트로 갱신하고 R1 배터리는 제외합니다. 잔량을 읽을 수 없으면 `안경 --`로 표시합니다. 폰 배터리 표시는 넣지 않았습니다.
- 휴대폰 HUD 미리보기의 최대 높이를 제한하여 긴 답변이 설정 화면 전체를 밀어내지 않게 했습니다.

이번 Mac에는 MLX 모델과 런타임을 설치하고 실제 GPU 추론, 잡음 제외, 트리거 판정, 사용자별 SQLite 저장까지 검증했습니다. 게이트웨이를 다시 시작하고 안경 앱을 새 패키지로 업데이트해야 모든 변경이 적용됩니다. 기존 EmbeddingGemma 2 + JEV, 도구, 장기 기억 처리는 계속 기존 `/api/chat` 경로를 사용합니다.

## 1.1.1 — 음성 필터, 설정 유지, 전사 기록 창

현재 패키지는 1.1.1이며 기본 서버 주소는 `http://192.168.1.4:2806`입니다.

- 서버에 Silero ONNX 음성 감지를 추가했습니다. 음량만 큰 비음성 구간을 Whisper에 보내지 않고, 음성 주변을 남겨 전사합니다. 기본 **말소리 감지 → 엄격**을 사용하고 작은 목소리를 놓치면 **표준**으로 바꿉니다. 합성 백색소음·팬 소리·톤·충격음 제외와 한국어 음성 통과를 테스트했습니다. 음성과 동시에 섞인 잡음을 분리하거나 TV의 말소리를 사람 대화와 구별하는 기능은 아닙니다.
- **전사 대상 → 내 목소리 우선**은 SDK가 `speakerRole=other`로 분류한 프레임을 제외합니다. 분류 정보가 없으면 일반 음성 필터를 적용합니다. 기본 **대화 음성**은 나와 상대방을 모두 기록합니다.
- 설정과 세션 토큰은 Even SDK의 `setLocalStorage`/`getLocalStorage`로 저장·복원합니다. 업데이트 후 한 번 로그인하고 설정을 저장하세요. 비밀번호는 저장하지 않으며 세션 만료·서버의 로그인 해제 이후에는 다시 로그인해야 합니다. SDK 저장소에 실패하면 오류를 표시합니다.
- 전사 기록은 별도 모달에서 열고 기록 영역만 스크롤합니다. 닫으면 설정 화면으로 돌아옵니다. 긴 기록으로 설정 저장 버튼이 밀려 내려가지 않습니다.

### 본인만 사용하는 베타 배포

공개 스토어에 게시하지 않고 베타 채널만 사용할 수 있습니다. 웹 허브에서 새 패키지를 업로드하고 본인의 Even 계정 이메일을 베타 테스터로 초대합니다. 초대를 수락하여 **Active** 상태가 된 뒤, 사용할 빌드를 **beta** 채널에 지정하세요. 휴대폰 Even 앱의 베타 목록에서 설치합니다. 개인 빌드와 달리 베타 설치는 안경 메뉴 실행을 지원합니다. 공개 스토어의 제출·게시 단계는 별도이며 이번 작업에서는 업로드나 초대를 실행하지 않았습니다.

공식 안내: [베타 설치 조건](https://hub.evenrealities.com/docs/cli/testers), [베타와 공개 배포](https://hub.evenrealities.com/docs/cli/builds), [테스트 모드 비교](https://hub.evenrealities.com/docs/test).

## 1.1.0 — 연속 전사와 AI 트리거

현재 생성한 `dkst-ai-gateway.ehpk` 1.1.0의 서버 주소는 `http://192.168.1.4:2806`입니다. 게이트웨이 서버도 이번 버전으로 다시 실행해야 합니다.

1. 로그인 후 모델을 선택하고 **음성 모드 → 연속 전사**를 선택합니다.
2. **AI 트리거 워드**를 입력하고 **설정 저장**을 누릅니다. 기본값은 `이븐`입니다.
3. 마이크 버튼 또는 G2를 한 번 탭하면 녹음을 시작하고 다시 탭하면 중지합니다.
4. 일반 발화는 전사 후 날짜·시각과 함께 기존 `memory/memory.db`의 `stt_transcripts` 테이블에 저장됩니다. 마이크 원본 오디오는 DB에 저장하지 않습니다.
5. `이븐 오늘 일정을 알려줘`처럼 트리거가 포함되면 뒤의 질문을 기존 `/api/chat`으로 보냅니다. 트리거만 말했다면 다음 발화를 질문으로 사용합니다. 최근 전사 8개를 대화 맥락으로 전달하며, 사용자별 도구·장기 기억·EmbeddingGemma 2 + JEV 설정은 기존 서버가 처리합니다. 전사 전체를 장기 기억에 자동 등록하지는 않습니다.
6. **날짜별 전사 기록 → 기록 보기 / TXT 저장**으로 본인 계정의 기록을 확인합니다. 날짜는 휴대폰의 시간대를 기준으로 조회합니다. 향후 요약 기능을 붙일 수 있도록 원문과 시각을 분리 저장하며, 자동 요약은 아직 없습니다.

발화는 약 0.9초 무음 또는 최대 12초 단위로 구분합니다. 전사 결과는 발화 구간이 끝난 뒤 표시되므로 단어 단위 실시간 자막과는 지연이 다릅니다. 연속 녹음 중 AI 답변을 처리하는 동안에도 다음 발화를 수신합니다. 처리 대기가 12구간을 넘으면 녹음을 중지합니다. 오류가 난 음성 구간은 앱이 열린 동안 재시도 대기하며, 서버에 저장되지 않은 상태에서 앱을 닫으면 사라집니다. 연속 모드의 TTS는 재녹음을 방지하기 위해 재생하지 않습니다.

Whisper Base를 실제 ONNX 런타임에 연결했습니다. 16 kHz mono PCM16/WAV를 지원하며 모델은 서버에서 오프라인 실행됩니다. 모델 관리자에서 STT를 설치할 때 Python 3.12 환경과 Optimum ONNX 런타임도 설치합니다. 기존 모델만 설치한 사용자는 STT를 다시 다운로드해 빠진 보조 파일과 런타임을 설치해야 합니다. 이번 Mac에는 설치와 한국어 합성 음성 테스트까지 완료했습니다. 일부 단어가 잘못 인식될 수 있습니다.

**호출어의 범위:** 여기서 저장하는 트리거는 이 앱이 열린 상태에서 연속 녹음할 때 작동합니다. 이를 Even AI의 전역 앱 실행 단축어로 자동 등록하는 공개 SDK API는 확인하지 못했습니다. EDITH의 공개 manifest에도 별도 호출어 선언은 보이지 않습니다. Even AI의 Shortcut center 및 실제 기기 동작은 별도로 확인해야 합니다. 앱을 닫은 상태의 호출이나 아이폰 잠금 상태의 지속 녹음은 보장하지 않습니다.

## 지금 G2에서 실행하기

1. 휴대폰의 Even Realities 앱과 같은 계정으로 <https://hub.evenrealities.com/login>에 로그인합니다.
2. 휴대폰 앱을 완전히 종료한 뒤 다시 열고, Even Hub 탭의 개발자 메뉴에서 **Scan QR**을 선택합니다.
3. 휴대폰을 서버에 접근할 수 있는 Wi-Fi에 연결하고 아래 QR을 스캔합니다. G2는 휴대폰 앱에 연결되어 있어야 합니다.

   ![G2 개발 미리보기 QR](g2-preview-qr.png)

   QR 주소: <https://192.168.1.4:8080/plugins/even-realities/>

4. 앱의 서버 주소가 `https://192.168.1.4:8080`인지 확인하고 게이트웨이 계정으로 로그인한 뒤 모델을 선택하고 설정을 저장합니다.
5. G2 또는 화면의 마이크 버튼을 한 번 눌러 녹음하고 다시 눌러 전송합니다. G2를 두 번 탭하면 시스템 종료 확인창을 엽니다.

게이트웨이는 계속 실행되어 있어야 합니다. 서버는 실행 작업 폴더 아래의 `plugins/even-realities`를 제공하므로 이 폴더를 유지하세요. 음성 인식에는 게이트웨이 Asset Manager에서 STT 모델을 먼저 설치해야 합니다. G2에는 스피커가 없으며 TTS는 휴대폰/이어폰에서 재생됩니다. 자동 재생이 제한될 수 있어 기본값은 꺼짐입니다.

### 인증서 때문에 열리지 않을 때

확인된 서버는 HTTP로 접근한 앱 페이지를 HTTPS로 리다이렉트하며, HTTPS에는 자체 서명 인증서가 적용되어 있습니다. 휴대폰에서 이 인증서를 신뢰하지 않으면 Even 앱의 WebView에서도 로드가 실패할 수 있습니다. 휴대폰에서 신뢰되는 인증서와 그 인증서에 맞는 주소를 사용하세요. 일반 브라우저의 경고를 한 번 통과하는 것만으로 Even 앱에서도 신뢰되는 것은 아닙니다. 주소를 바꾸면 QR도 다시 생성해야 합니다.

### 설치 앱에서 `Load failed`가 나올 때

`Load failed`는 HTTP 401 인증 오류와 다릅니다. 설치 앱은 휴대폰의 loopback WebView 주소에서 실행되므로 게이트웨이 API에 CORS 처리가 필요합니다. 게이트웨이의 `evenHubCORS` 미들웨어는 앱에서 사용하는 API에 한해 loopback Origin을 허용하고 로그인 사전 요청에 204로 응답합니다. 인증에는 세션 쿠키 대신 명시적인 Bearer 토큰을 사용합니다. 이 서버 수정은 게이트웨이 실행 파일을 다시 빌드하고 앱을 완전히 종료한 뒤 실행해야 적용됩니다. 안경 앱 1.0.1은 다시 설치하지 않아도 이 서버 수정을 사용할 수 있습니다.

## 수정 후 빌드와 QR 재생성

이 폴더에서 실행합니다. Node.js 20.17+, 22.13+ 또는 23.5+가 필요합니다.

```sh
npm ci
npm run build -- --server https://192.168.1.4:8080
npm test
npm run qr -- --url https://192.168.1.4:8080/plugins/even-realities/ --external
```

`bundle.js`에는 공식 SDK가 포함됩니다. `index.html`만 복사하거나 `plugin.js`만 직접 로드하면 안 됩니다. `npm run build`의 `--server`를 생략하면 페이지를 연 서버 주소를 기본값으로 사용합니다.

## 개인 설치용 패키지

아래 명령은 예시 서버 주소 `http://192.168.1.4:8080`을 사용합니다. 이번에 생성한 1.1.0 패키지의 실제 주소는 위의 1.1.0 절을 참고하세요. HTTPS 자체 서명 인증서 때문에 아이폰 Prototype Mode의 페이지 로딩이 막히는 경우를 피하기 위한 로컬 Wi-Fi 테스트용입니다. 앱 파일은 패키지 안에서 로드하고 API만 HTTP로 호출합니다. HTTP API에는 TLS 암호화가 없으므로 신뢰하는 로컬 Wi-Fi에서 사용하세요. 실제 아이폰의 HTTP 허용 정책과 G2 동작은 설치 후 확인해야 합니다.

1.0.2는 LM Studio의 `key`와 `display_name` 필드를 지원하여 `[object Object]` 모델명 표시를 수정하고, 대화 요청에는 실제 모델 ID를 전달합니다.

웹 허브에서 프로젝트의 Builds에 패키지를 업로드한 뒤, 같은 계정의 아이폰 Even 앱에서 **Me → Apps → Private builds**를 열어 설치합니다. 개인 빌드는 휴대폰에서 실행하는 용도입니다. 안경 메뉴에서 실행하려면 베타 배포와 본인 계정의 테스터 등록이 필요합니다.

```sh
npm run pack -- http://192.168.1.4:8080
```

`dkst-ai-gateway.ehpk`가 생성됩니다. 서버 주소는 번들의 기본값과 `dist/app.json`의 네트워크 허용 목록에 함께 반영됩니다. 패키지를 배포할 때도 실제로 휴대폰에서 접근 가능한 서버 주소가 필요합니다. 생성된 파일을 공식 개발자 포털에서 개인 빌드로 등록한 뒤 같은 계정의 휴대폰 앱에서 설치할 수 있습니다. QR 개발 미리보기에는 이 업로드 과정이 필요하지 않습니다. 이 프로젝트에서는 패키지를 로컬에만 생성하며 업로드하지 않습니다.

빌드·패키징 및 모의 브리지 검증을 완료했습니다. 실제 G2에서의 녹음, 한글 표시, Bluetooth 연결, 휴대폰 인증서 신뢰는 기기에서 확인해야 합니다.
